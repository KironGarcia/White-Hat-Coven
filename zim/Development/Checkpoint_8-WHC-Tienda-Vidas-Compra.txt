===== Pixel sharpness (MANDATORY for next screens) =====
Every pixel-art PNG that goes on device (new or updated):

1. Keep master **1×** in ''sprites-piskel/.../master/''
2. Ship the **8× nearest-neighbor** PNG (no blur / bilinear)
3. Code uses **logical 1×** sizes for layout
4. React Native ''<Image>'': ''resizeMode="stretch"'' + ''resizeMethod="scale"'' (Android)

Never scale a 1× PNG straight to the phone — it goes soft. **Shop header (2026-08-13) is the approved reference.** Aviso + boss art must follow this before layout QA.

Also for overlays (shop / aviso / boss):
* Measure the **real container** (''onLayout''), not only ''useWindowDimensions''
* Honor **safe area** (''useSafeAreaInsets'') — header/footer/buttons never sit under the Android nav bar
* Balloon text: **shrink the font until the full phrase fits** — never ellipsis / never clip

===== Incident log — Metro 500 + white screen (2026-08-13 aviso pass) =====
Kiron hit two failures while polishing the intermediate screen. **Write this down so the next chat does not re-debug from zero.**

==== Error 500 — Unable to resolve module (Metro) ====
* Symptom: Dev Client white error page. ''The development server returned response error code: 500''.
* Bundle URL was ARGOS front (expo-router), origin file: ''argos-app/WHC/demo1/src/assets.ts''.
* Missing file: ''../../sprites-piskel/ORBs/Orb-azul-jump.png'' (obsolete jump sheet; run uses normal / subida / bajada).
* Why it “appeared” after an unrelated edit: Metro re-parses **every** ''require()'' in ''assets.ts'' when that module changes. One dead path = the **whole Jogo tab fails to bundle**. The game does not logically need the obsolete PNG.
* Fix: delete the unused ''require'' (or restore the file). Do **not** leave backup requires pointing at deleted sprites.
* Before shipping an ''assets.ts'' change: confirm every ''require('...png')'' path exists on disk.
* After the 500: Reload on the phone. If the error sticks, restart Metro (cache) then Reload.

==== White / blank screen — no intro ====
* Symptom: tap WHC icon → empty/white (or dark empty). Intro never shows.
* Causes stacked:
  1. Same Metro 500 (bundle never loads).
  2. **Pending invasion in AsyncStorage** — after landing on the fake platform, reopen **skips intro** and opens aviso. That is intended. If aviso then crashes (native), it looks like “intro is dead”.
  3. Android Fabric: ''adjustsFontSizeToFit'' on Press Start 2P in the aviso balloon can crash the scene.
  4. Full-screen glitch as one stretched 4×-wide strip can OOM / fail to paint.
* Fix path already in code: drop dead requires; balloon without ''adjustsFontSizeToFit''; glitch as stacked frames filling the **parent**; ErrorBoundary in ''App.tsx'' shows the JS error instead of a blank view; ''tabBarStyle: { display: none }'' on the Jogo tab so ARGOS does not reserve footer space.
* If intro is missing but aviso is correct: invasion persist is working. Clear pending invasion only if you need the intro for QA.
