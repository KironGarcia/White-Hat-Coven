=== Intro — PADRÃO FINAL (locked — do not regress) ===
File: ''IntroScreen.tsx''

Background rules:
1. ''onLayout'' measures real game container (not only window).
2. Fill height + small vertical overscan (no black bands).
3. Sides: crop ≤ ~1 cm/side, then stretch remainder (title readable).
4. Nudge ~2 mm right (''DESLOCAMENTO_DIREITA_PX = 8'') for title centering.
5. Image **must** set explicit width/height (''absoluteFill'' alone blew PNG to native size).
6. Rejected: pure ''cover'' / pure ''contain''.
