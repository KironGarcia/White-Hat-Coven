===== Block G — Fixes after that APK (in code, next APK must include them) =====

==== G1 — Shop / safe area ====
Crash: “No safe area value available. Make sure you are rendering <SafeAreaProvider> at the top of your app.”

Cause: ''TiendaScreen'' and ''BossArenaScreen'' call ''useSafeAreaInsets()''. ARGOS used to wrap the tree; standalone ''App.tsx'' did not.

Fix: ''SafeAreaProvider'' wraps the app in ''App.tsx''.

==== G2 — Pixel font ====
TTF is ''assets/fonts/PressStart2P-Regular.ttf''. Internal family name is '''Press Start 2P''' (not ''PressStart2P'').

Android APK ignored the JS alias. Also ''fontePronta = fonteCarregada || !!erroFonte'' let the game run without the font.

Fixes:

* ''FONTE_PIXEL = 'Press Start 2P''
* ''app.json'' expo-font plugin lists the TTF
* Do not open gameplay if ''useFonts'' fails
* ''useFonts({ [FONTE_PIXEL]: ARQUIVO_FONTE_PIXEL })''

==== G3 — Three languages ====
Dictionaries already existed (''textos-jogo.ts''). Standalone had no selector; language used to come from ARGOS.

Fixes:

* ''IdiomaJogoContext'': ''definirIdioma'' + AsyncStorage ''@whc_demo1/idioma'' (fallback read ''@argos/idioma'')
* Intro floor: ''SeletorIdiomaJogo'' (PT / EN / ES drawer, same idea as ARGOS, WHC look)
* Keys: ''t.idiomas.rotulo / pt / en / es''

===== Block H — CURRENT BLOCKER (latest APK does not open) =====

Kiron screenshot 2026-08-25 after the font / SafeArea / language APK:

'''O jogo travou ao abrir.'''

Red text:

* Error: Call to function '''ExpoAsset.downloadAsync''' has been rejected.
* Caused by: Module '''expo.modules.interfaces.filesystem.AppDirectories''' not found. Are you sure all modules are linked correctly?

Likely chain: we added '''expo-asset''' (and the expo-asset config plugin) so Metro could bundle fonts. In the '''release APK''', ''expo-font'' / ''useFonts'' then calls ''ExpoAsset.downloadAsync''. Native side is missing '''AppDirectories''' (Expo filesystem interface). Typical causes: incomplete native link of expo-asset / expo-file-system on SDK 53, plugin list too aggressive, or a missing peer (often '''expo-file-system''').

'''This is the first task of the next chat.''' Do not start another EAS build until the app opens past this error (Expo Go or a local debug build if possible, then APK).

Suspect files:

* ''WHC/app.json'' plugins: ''expo-font'' (with fonts array), ''expo-asset''
* ''WHC/App.tsx'' ''useFonts''
* ''WHC/package.json'': ''expo-asset'' ~11.1.7, '''no''' ''expo-file-system'' listed
* ''WHC/src/tipografia.ts''

Hypothesis to test (next session, not done):

* Add SDK-aligned ''expo-file-system'' via ''npx expo install expo-file-system''
* Or stop loading the TTF through ExpoAsset.downloadAsync (embed font only via config plugin / native, avoid runtime download)
* Or remove the ''expo-asset'' config plugin if it is enough as a JS dependency without the plugin
* Confirm autolinking in the EAS Android native project
