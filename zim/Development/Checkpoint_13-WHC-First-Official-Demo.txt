===== Block B — Demo loop (do not change unless Kiron asks) =====

* Phase 1 map ''fondo-fase1'' → fake/boss from '''300 m''' → victory → phase 2 ''fondo-fase2''.
* Phase 2 → fake/boss from '''600 m''' → phase 3 ''fondo-fase3''.
* Phase 3 → fake/boss from '''900 m''' → farewell + wood '''Sair''' → intro. Does not keep climbing.
* Fakes: one '''guaranteed''' at the range, then '''random''' (chance 0.1) until the player '''lands'''. At most one fake on screen; never two in a row. Missing a fake does '''not''' kill the range.
* Boss arena: floor + red bar + orb auto-shot. '''No''' in-arena platforms / jump / patch. Tilt left/right on the floor.
* Shop: extra platforms at 50 m, 200 m, then every 300 m. Pause run; resume on close.

===== Block C — Audio (crash-safe path) =====

Files in ''WHC/assets/audios/''. Plugin ''plugins/with-audios-android.js'' copies them to Android ''res/raw'' (valid names). Playback: ''android.resource://com.whitehatcoven.demo1/raw/…'' via ''expo-av''. '''No''' ''require()'' of audio, '''no''' ''Asset.downloadAsync''. If a cue fails, the game stays mute — it must not crash.

''src/systems/audio-jogo.ts'' + ''App.tsx'' (BGM by screen).

===== Block D — Anti-crash (still mandatory) =====

* ''SafeAreaProvider'' at the root of ''App.tsx''.
* No ''useFonts''. Font only via ''app.json'' expo-font plugin (Android XML family '''Press Start 2P''').
* No ''expo-asset'' in plugins.
* Audio only via ''android.resource'' / ''res/raw''.
* Full ''node_modules'' before EAS (empty folder → cannot resolve expo-font plugin). ''npm ci'' then build.
