===== Block A — Hook cycle (locked) =====

* First drop '''7 s''' after entering the fight; then '''7 s''' between cycles (''PATRULHA_ANZOL_S'').
* Drop is '''fast''' (''DESCIDA_ANZOL_S = 0.35'', floor ~850 px/s). '''3 s''' parked at orb height (''PARADO_ANZOL_S''). Up in '''2 s''' (''SUBIDA_ANZOL_S'').
* Cart stops on drop / park / rise. Patrols on the strip only while retracted.
* Hit-box umbrella: virus that hits the hit-box ceiling '''dies'''; hook that hits it '''bounces up'''.
* Next drop does '''not''' start while the orb is still stolen (''orbForaDaCabeca''). The 7 s patrol clock waits until the orb is back on the head.

===== Block B — Fishing + orb hold =====

* Hit test is the '''purple tip''' of the 37×56 art (''PONTA_ANZOL_ART = { x: 6, y: 33, … }''), not the whole hook sprite.
* Tip overlaps the '''top 5 mm''' of the orb (''MARGEM_PONTA_ORB_PX''). Orb hangs from the tip — it does '''not''' enter the boss house.
* On catch: ''orbAmarrada = true''. The '''7 s hold (''SEQUESTRO_ORB_S'') starts only when the hook is back in '''patrulha''' (top)'''. Counting from the catch (while rising) was wrong — the orb arrived at the top and immediately left.
* After 7 s at the top: blink (''DURACAO_PISCA_SOLTA_ORB_S = 0.7''), vanish, reappear on the mage’s head. Then shooting works again.
* Cannot shoot while the orb is off the head (''orbForaDaCabeca'').

===== Block C — HAHAHA (visual) =====

* Sheet ''Pishing-Man-HAHAHA.png'' (4 frames, 3 FPS). Frame 0 is closed-mouth (looks like idle) — '''start at frame 1''' (''FRAME_INICIAL_HAHAHA_BOSS'').
* One-shot on catch (''tokenHahahaBoss''). Read the token '''before''' ''atualizarAnzolArena'' or the SFX never fires.
* Duration ''DURACAO_HAHAHA_BOSS_S = 4/3 ≈ 1.33 s''. Hit animation still wins if both are active.
