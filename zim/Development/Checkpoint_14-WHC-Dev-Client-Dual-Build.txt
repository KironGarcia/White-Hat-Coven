===== Block C — FORBIDDEN in config (APK crash on open) =====

These already killed a standalone APK. They apply to '''preview and development'''. Do not add them “just for dev”.

==== C1 — Never put ''expo-asset'' in ''app.json'' plugins ====

JS dependency ''expo-asset'' may stay (expo-font pulls it). '''The config plugin must stay out.''' It led to ''ExpoAsset.downloadAsync'' → module '''AppDirectories''' not found → game never reaches intro.

==== C2 — Never load fonts in JavaScript ====

Forbidden: ''useFonts'', ''Font.loadAsync'', ''require()'' of the TTF in JS.

Allowed: expo-font '''config plugin''' only (Android XML family '''Press Start 2P''' + ''ReactFontManager''). ''src/tipografia.ts'' exports the family name string. See Checkpoint 12 Block A.

==== C3 — Never load audio through JS bundles or downloadAsync ====

Forbidden: ''require()'' of mp3/ogg/wav, ''Asset.downloadAsync'', Expo Go asset URIs.

Allowed: plugin ''plugins/with-audios-android.js'' copies files to Android ''res/raw''. Playback: ''android.resource://com.whitehatcoven.demo1/raw/…'' via expo-av. If a cue fails, stay mute — '''do not crash'''.

Raw name of the intro loop is '''audio_intro_fondo''' (Spanish ''fondo''). Mixing that name silences intro while shop/battle still work.

==== C4 — Do not add plugins that download assets at runtime ====

Any new plugin that calls ''downloadAsync'' / AppDirectories on launch is a crash candidate. Prefer native bundle (config plugin / ''res/raw'' / Android assets). Test on a '''preview''' APK before calling it safe.

==== C5 — Keep ''SafeAreaProvider'' ====

Root of ''App.tsx''. Shop / aviso / intro crash without it (“No safe area value available”).

==== C6 — Keep the plugin list small ====

Current allowed plugins in ''app.json'':

* expo-font (TTF + Android family '''Press Start 2P''')
* expo-av (''microphonePermission: false'')
* expo-sensors (motion copy)
* ''./plugins/with-audios-android''

Do '''not''' add: expo-asset plugin, expo-updates (not needed for this demo), extra filesystem plugins “to fix fonts”.

==== C7 — Full ''node_modules'' before EAS ====

Empty folder → “Failed to resolve plugin expo-font”. Always ''npm ci'' in ''WHC/'' then build.

==== C8 — Stay on SDK 53 ====

Bump to SDK 54/57 is a rewrite risk for the crash-safe font/audio path. ''expo-dev-client'' must stay the SDK 53 bundle (''~5.2.4'').
