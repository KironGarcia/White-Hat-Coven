===== Block A — ANTI-CRASH (do not undo) =====

These two crashes already happened on device. Both are closed in code.

'''Shop / aviso / intro — SafeArea'''

* Error: “No safe area value available… render <SafeAreaProvider>”
* Fix: ''App.tsx'' wraps the tree with ''SafeAreaProvider''. Keep it. ''TiendaScreen'', ''IntroScreen'', ''BossArenaScreen'' use ''useSafeAreaInsets()''.

'''Open — ExpoAsset.downloadAsync / AppDirectories'''

* Error: ''ExpoAsset.downloadAsync'' rejected → module ''expo.modules.interfaces.filesystem.AppDirectories'' not found.
* Cause: ''useFonts'' from ''expo-font'' calls ''Asset.downloadAsync''. On this EAS APK the native AppDirectories module does '''not''' link, even with ''expo-file-system@18.1.11'' as a direct dependency.
* '''Reset rule: never call ''useFonts'' / ''Font.loadAsync'' on the standalone APK.''' Pixel font must be registered by the '''expo-font config plugin''' (native), not downloaded at runtime.
* ''src/tipografia.ts'': ''FONTE_PIXEL = 'Press Start 2P''' (TTF internal family). No ''require()'' of the TTF in JS.
* Do '''not''' put ''expo-asset'' back in ''app.json'' plugins (JS dependency may stay).

If a later feature (audio, extra fonts) needs ''downloadAsync'', it is a '''new crash risk'''. Prefer native bundle / Android assets, not runtime download.
