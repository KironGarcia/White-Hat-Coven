===== Block A — Arena combat (locked on device) =====

* Floor: arena fill ''#161616'' + ''piso-tela-boos'' (full-frame PNG). Drops (virus / patch) draw '''behind''' the floor strip and clip at ''pisoY'' so they vanish under the rodapé, not over it. Mage + orb draw '''above''' the floor.

* '''Several shots can be in flight at once''' (''arena.disparos[]''). Do '''not''' wait for the previous laser animation to finish. Queue taps (''pedidosDisparo''). Soft gap ''INTERVALO_DISPARO_BOSS_S = 0.05''. Cap ''MAX_DISPAROS_NA_TELA = 8''. Every spawned shot plays SFX.

* Boss HP is a number on the portrait (not the HUD art ''barra de vida boss.png'' — still unused). Size: 14 px + '''1 mm'''. On boss hit the number '''blinks red''' with the hit animation.

* ''androidImplementation: 'MediaPlayer'''
* URI for bundled raw = '''only the resource name''' (''disparo_audio'', …). Native ''getIdentifier''. '''Not''' ''android.resource://pkg/raw/name'' (MediaPlayer stays mute).

===== Block F — Crashes and errors we already paid for (do not repeat) =====

'''Open / audio thread'''

* ExoPlayer: ''Player is accessed on the wrong thread'' when ''release()'' runs off the main looper (Fast Refresh, BGM swap, death on boss). Stay on '''MediaPlayer'''. Do not “fix” with ExoPlayer without a native main-thread ''release'' patch.
* ''android.resource://…/raw/nome'' + MediaPlayer = '''silence'''. URI = resource '''name only'''.
* Skipping ''unload'' in ''__DEV__'' hides the crash and was rejected. Unload stays; serialize with ''naFilaAudio''.
* ''useFonts'' / ''Font.loadAsync'' / expo-asset '''plugin''' / ''Asset.downloadAsync'' on launch → AppDirectories / open crash. Font = config plugin + ''ReactFontManager''. Checkpoint 12.

'''Metro / Dev Client'''

* Metro default ''assetExts'' include '''wav''' and '''mp3''', '''not ogg'''. ''require('…/boss-music.ogg')'' → '''500 UnableToResolveError''' (''boss-music'' with no extension). Game would not load. Fix: ''metro.config.js'' '''push 'ogg''''. '''Restart Metro''' (reload on the phone is not enough; config is read at server start).
* Linux is case-sensitive. Disk ''Boss-music.ogg'' vs resolver ''boss-music'' failed. Keep a lowercase ''boss-music.ogg'' (and require that path). Plugin copies ''boss-music.ogg'' → ''boss_music.ogg''.
* New ''res/raw'' files are '''invisible''' until a '''new development/preview APK'''. Metro reload cannot inject them. For wav/ogg not yet in the binary: pack via ''require'' (only after the extension is in ''assetExts'') + copy to ''FileSystem.cacheDirectory'' via ''FileSystem.downloadAsync'' from the asset URI — '''not''' ''Asset.downloadAsync''. If the cache file already exists, bump the cache filename when the audio bytes change (hit SFX v2…v5) or the device keeps the quiet file.
* Do not add a ''require()'' of a new audio format until ''assetExts'' allows it. That 500 takes down the '''whole''' bundle, not just the cue.

'''Arena loop / logic'''

* ''BossArenaScreen'' must ''requestAnimationFrame(passo)'' at the '''start''' of ''passo'', same as the run. Scheduling it after ''setTick'' cancelled the loop → mage, hook, drops frozen (boss still animated via ''FramesAnimator'').
* ''seguirAcimaDaCabeca'' must stay imported from ''entities/orb.ts'' (crash when sequestro called it without import). With fishing off, sequestro is zeroed; orb still follows the head.
* Do not set ''vivo = false'' on the same frame as a virus hit; play ''muerto'' first (0.5 s).
* One ''arena.disparo'' object blocked the next tap until salida+travel+impacto finished. Multi-shot list is the rule now.

'''Feel / mix'''

* Boss tilt must not copy run 1:1. High sensitivity without a deadzone = scoot after centering the phone. Keep stop zone 0.1; only the start threshold is smaller.
* Patch faster than virus = patch visually covers the virus. Same fall speed.
* expo-av volume is '''0–1'''. A quiet WAV/OGG at volume 1.0 is still quiet — raise '''gain on the file''' (ffmpeg ''volume=''), then bump the cache name. Do not expect 1.5 in ''setVolumeAsync''.
