===== Why this exists =====
The engagement hook of WHC is not only altitude record — it is **controlled rage**: feeling what a hack feels like in fiction, then learning via Oráculo to regain power. This checkpoint freezes the two first bosses and their mechanics so they are not lost again.

===== Demo scope =====
* **Phase 1 boss:** Phishing Man (build first / MVP invasion).
* **Phase 2 boss:** Capitán Pix Pirata (differentiate phases; almost ready in Kiron’s head/art pipeline).
* More bosses stay on a waitlist (powers TBD when Kiron recalls them). One boss is enough to prove the loop; two show variety.

===== Shared boss-screen framework (both bosses) =====

==== Entry ====
* Trigger (Game Bible): land on fake **phishing platform** (trap) → invasion.
* Black **glitch** screen → boss frame/box UI appears.
* World aesthetic goes **raw/debug**: pretty masks stripped; platforms use ''Hit-box-plataforma'' look with a **label strip** under the platform.

==== Platform labels (chaos layer) ====
* Normal labels examples: ''Plataforma.1'', ''Plataforma.2'', ''Plataforma.3''.
* Malware labels: ''Plataforma.mwr1'', ''Plataforma.mwr2'' (each boss defines what each mwr does).
* Stepping on ''.mwr*'' activates that boss’s malware effect until cancelled.

==== Hearts ====
* Player has **2 hearts** in normal run **and** in boss screen.
* Lose both → death / run ends (same rule).

==== Patch item (pendrive) ====
* Asset candidate already in repo: ''sprites-piskel/mago-sprites/Patch-iten.png''.
* Spawns randomly with **low probability**.
* Collecting patch:
  1. Cancels active malware.
  2. Opens the **hit window**: floor locks under the player (stop falling); only gyro left/right; orb starts shooting.
  3. Boss is briefly **stunned**; a **moving breach bar** appears on the boss box (shield gap). Player must chase the bar with tilt to land hits.
* Stun duration: **TBD** (tune later).

==== Orbe / damage (Oráculo bridge) ====
* Learn topic in ARGOS bot → earn **encanto** → **golden/super orb**.
* Hit damage:
  * With golden orb: **10** damage per successful breach hit.
  * Without: **1** damage per hit.
* Boss HP baseline: **~100**.
  * With golden orb: ~**10 hits** (~2 patches if window allows).
  * Without: ~**100 hits** — possible but brutal; needs several patches before the stun ends / boss kills you.
* This keeps “fight without knowledge” possible but makes Oráculo feel mandatory for sanity.

==== Session coins vs total wallet (monetization-safe) ====
* **Session wallet:** resets to 0 each run; only this can be stolen/drained in boss fights.
* **Total wallet:** grows only when the run ends (death or clear) by adding session earnings.
* IAP coin packs feed **total**, never touchable by boss drain → no “game stole my paid money” rage.

===== Boss 1 — Phishing Man (Phase 1) =====

==== Fantasy ====
Classic bait. Hook pulls you; malware inverts spatial habits.

==== Oráculo topic ====
* Ask what **phishing** is + phishing techniques → encanto → golden orb.

==== Signature power ====
* Throws a **fishing hook / anzuelo**.
* On hit: player is hooked and dropped at a **random map position** (often unsafe / few platforms). Survival depends on skill + luck to land again.
* Fairness note for implementation: telegraph the hook; random drop should still allow a chance to recover (avoid pure instant death RNG).

==== Malware ====
* ''.mwr1'': reverses vertical flow — platforms that used to come from above now come **from below upward** (confuses muscle memory).
* ''.mwr2'': (shared framework) rarer / harder to roll; effect TBD for this boss if used, or reserved — Phase 1 can ship with mwr1 first.

==== Coins on boss screen ====
* **No coin collectibles** on Phishing Man screen (contrast with Pix).

===== Boss 2 — Capitán Pix Pirata (Phase 2) =====

==== Fantasy ====
The boss that hurts where it hurts: the **pocket**. Rage weapon for “if I get hacked I lose money” — fictional, session-scoped.

==== Oráculo topic ====
* TBD precisely (PIX fraud / social engineering / fake payment links — align when building Phase 2). Must teach a money-theft pattern.

==== Signature economy trap ====
* Boss screen **has coins on almost every platform** → player thinks “jackpot”.
* Mix of normal coins + **Moneda-pirata** (green dot = infected).
* Collecting pirate coin: **−1 session coin** each.
* Green dot must be **more visible** (Kiron will enlarge) so failure feels “I fell for it”, not “unfair sprite”.

==== Malware ====
* ''.mwr1'': drains session coins **−5** repeatedly until patch (calibrate so it hurts but doesn’t feel like real-money theft — session only).
* ''.mwr2'': removes **1 heart**; **much rarer** so it is scary but not constant panic.

==== Economy calibration ====
* Reaching Phase 2 might imply ~100 session coins collected.
* Failing the boss slowly can wipe session to **0** easily — intended assault fantasy.
* Never drain **total** wallet.
